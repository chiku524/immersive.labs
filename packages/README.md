# Packages

| Package | Description |
|---------|-------------|
| `@immersive/studio-types` | Shared TypeScript types for studio asset specs and job manifests. See `docs/studio/json-schema-spec.md`. |
| `com.immersivelabs.studio` | Unity Editor importer (`packages/studio-unity`) — import worker packs into URP projects. |
| `ImmersiveStudio` | Unreal Engine 5 Editor plugin (`packages/studio-unreal`) — import worker packs (GLB + PBR + manifest). |
| `packages/studio-godot` | Godot 4 runtime helpers — spawn scaled GLB props and apply sidecar ORM PBR (`docs/studio/godot-import-conventions.md`). |
| `immersive-studio-bevy` | Bevy 0.19 helpers — spawn GLB props via `WorldAssetRoot` and apply sidecar ORM PBR (`docs/studio/bevy-import-conventions.md`). |
